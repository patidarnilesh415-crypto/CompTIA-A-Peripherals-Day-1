# Day 4 - Connecting and Testing Peripherals

## 1. Connect and Test a USB Webcam

1. Connect the USB webcam to the computer.
2. Wait for Windows to detect the webcam.
3. Install any required drivers if prompted.
4. Open the default Camera app.
5. Check that the webcam is working properly.
6. Capture a photo to verify that the webcam works correctly.

## 2. Set Up and Test a Local Printer

1. Connect the printer to the computer using USB or connect it to the same network.
2. Turn on the printer.
3. Install the correct printer driver if required.
4. Open **Settings > Devices > Printers & scanners**.
5. Check that the printer is detected.
6. Print a test page to confirm successful installation.

## 3. Troubleshoot a Printer Not Detected

1. Unplug the printer's USB cable.
2. Open **Device Manager** in Windows.
3. Check for error icons or devices that are not recognized.
4. Reconnect the printer's USB cable.
5. In Device Manager, select **Scan for hardware changes**.
6. Check whether the printer is detected again.
7. If required, update or reinstall the printer driver.

## 4. Troubleshoot Webcam Video Not Displaying in Zoom

1. Check that the webcam works in the default Camera app.
2. Open Zoom and check the selected camera under **Video** settings.
3. Make sure no other application is using the webcam.
4. Check Windows camera permissions.
5. Go to **Settings > Privacy > Camera** and make sure camera access is enabled.
6. Make sure **Allow desktop apps to access your camera** is enabled.
7. Restart Zoom and test the webcam again.
