# Day 3 - Peripheral Troubleshooting

## 1. Common Issues with USB Keyboard or Mouse

| Issue | Possible Solution |
|---|---|
| Keyboard or mouse is not detected | Unplug the USB device and connect it to another USB port. |
| Device works intermittently | Check the USB cable/connector and try another USB port. |
| Some keys or mouse buttons do not work | Test the device on another computer and clean the affected keys/buttons. |
| Mouse cursor is not moving properly | Clean the mouse sensor and check the mouse surface. |
| USB device stops working after Windows starts | Restart the computer and check the device in Device Manager. |

## 2. Bluetooth Headphones Not Connecting to Phone

I would troubleshoot the problem step by step:

1. Make sure the headphones are switched on and have enough battery.
2. Turn Bluetooth off on the phone and turn it on again.
3. Open **Settings > Bluetooth** and check whether the headphones are listed.
4. If the headphones are listed but not connecting, select them and choose **Forget/Unpair**.
5. Put the headphones into pairing mode again.
6. Search for available Bluetooth devices and select the headphones.
7. If they still do not connect, restart both the phone and the headphones.
8. Check that the headphones are not already connected to another nearby device.

## 3. External Webcam Not Detected in Zoom on Windows 10

I would check the following:

1. Make sure the webcam is properly connected to the USB port.
2. Try another USB port and check whether the webcam light turns on.
3. Open **Device Manager** and check under **Cameras** or **Imaging devices**.
4. If the webcam has a warning symbol, update or reinstall its driver.
5. Go to **Settings > Privacy > Camera** and make sure camera access is enabled.
6. Make sure **Allow desktop apps to access your camera** is enabled so that Zoom can use the webcam.
7. Open Zoom settings and select the correct external webcam under **Video**.
8. Close other applications that may already be using the webcam and restart Zoom.

## 4. Printer Showing "Offline" on Windows

I would use the Windows printer troubleshooting options as follows:

1. First, check that the printer is switched on and connected to the computer or the same Wi-Fi network.
2. Open **Settings > Devices > Printers & scanners**.
3. Select the affected printer and open its management/options.
4. Run the available **Printer Troubleshooter**.
5. Follow the instructions shown by Windows.
6. The troubleshooter checks common problems such as printer connection, driver/settings issues, and printer status.
7. Apply the recommended fix if Windows finds a problem.
8. Print a test page to confirm that the printer is working.
